# বাজার দর (BazarDor)

## About the Project

BazarDor is a simple web application that helps people check daily market prices. Users can see different products, compare prices, and find useful market information. The main goal of this project is to make it easier for people to know the prices of daily necessary products.

## Technologies Used

- **Next.js** – For building the web application
- **JavaScript** – For application functionality
- **Tailwind CSS** – For styling and responsive design
- **DaisyUI & HeroUI** – For UI components
- **MongoDB** – For database management
- **Better Auth** – For user authentication
- **React Hot Toast** – For showing notifications

## Key Features

1. **Homepage:** Users can see popular products and market price information on the homepage.
2. **Product Details:** Users can view product information and its price.
3. **Category and Sorting:** Users can browse products by category and sort them by price.
4. **User Authentication:** Users can sign up, sign in, and use social login options.
5. **Profile Management:** Logged-in users can view and update their profile information.

## Project Purpose

This project is developed as part of an academic assignment. Through this project, I learned how to build a web application using Next.js, connect APIs, create responsive user interfaces, and implement user authentication.
